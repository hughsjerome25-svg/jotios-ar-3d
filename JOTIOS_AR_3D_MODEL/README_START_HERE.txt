JOTIOS WRLD — 3D MODEL AR EXPERIENCE

This is a SECOND AR project using the SAME JOTIOS WRLD Special Edition artwork as the tracking image.

Included:
- index.html
- targets.mind (reuses your existing compiled target)
- jotios-target.png
- ultimate-blue-model.glb

WHAT IT DOES
Scan the website QR code -> allow camera -> point at the same JOTIOS WRLD artwork -> the GLB model appears anchored to the artwork and its embedded animation is played.

HOW TO PUBLISH AS A SEPARATE AR EXPERIENCE
1. Create a NEW GitHub repository, for example: jotios-ar-3d
2. Upload ALL FOUR project files to the ROOT of that repository.
3. In Settings -> Pages, choose Deploy from a branch, main, /(root), Save.
4. Wait for the GitHub Pages URL to become live.
5. Open the URL on your phone and test against the same printed JOTIOS artwork.
6. Send the new live URL to ChatGPT to create a separate QR code.

IMPORTANT
- Do not replace your original video AR project unless you want this 3D version to take its place.
- This project already includes targets.mind, so you DO NOT need to compile the image again.
- Camera access requires HTTPS; GitHub Pages provides HTTPS.
